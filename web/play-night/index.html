For the host — run of show
  1. Ship first, play second. The week's TestFlight build goes out before the night; everyone updates before sitting down. Mixed builds can't share a match.
  2. Fill the table. The game only shows itself with a full lobby — contested cards, the re-pick pass, the six-player clock all need bodies in seats.
  3. First-timers get no help. Match one is the onboarding test. If it needs narration, the game failed, not the player.
  4. Observe, don't rescue. Write down every timer that expires and every rules question asked out loud — each one is a finding.
  5. Debrief while it's warm. Everyone fills this page before phones go away. Say the score out loud: “5 of 7 sent theirs last week.”
  6. File it. Findings become issues on the board within a day, and the next build's notes name what changed because of them.
